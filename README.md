# Hành Trình Toả Sáng · Nikki: Ngôi Sao Thời Trang

Trang theo dõi điểm đánh giá của Nikki: Ngôi Sao Thời Trang trên App Store và Google Play.

- Số liệu lấy từ trang công khai của App Store và Google Play, cập nhật mỗi giờ (GitHub Actions, file `.github/workflows/update-ratings.yml`).
- Mốc điểm, quà và thời gian sự kiện: `config.json`.
- Số liệu hiện tại và lịch sử: `data/ratings.json` (tự ghi, không sửa tay).
